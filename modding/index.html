04

Modding, reverse engineering, and breaking things just enough to understand them.

Field notes from Stardew Valley, where an active SMAPI habit turns into API archaeology more often than not. Mod sources are published on GitHub and linked per note.

  1. [01]

    RenameAnimal

    SMAPI mod for renaming animals without fighting the game’s input handling: quote-aware argument parsing so multi-word names survive intact, plus keybind configuration through GMCM.

    • C#
    • SMAPI
    • GMCM

  2. [02]

    Chat Commands, ported to Stardew Valley 1.6

    Ported Chat Commands to SDV 1.6: run console commands straight from the in-game chat box, with scrollable history, console mirroring and whisper/reply support. SMAPI removed ICommandHelper.Trigger along the way, solved by reflecting into SMAPI’s private CommandManager: the public API lost the capability, not the runtime.

    ChatCommands on GitHub
    • C#
    • Reflection
    • SDV 1.6

  3. [03]

    Serbian localization pipeline

    A large Ollama-powered pipeline for localizing Stardew Valley’s JSON files into Serbian, paired with the manual grind: one mod’s 62 JSON files translated by hand into Serbian Latin.

    • Ollama
    • JSON
    • Localization

The Chat Commands port has its own write-up on the blog.
